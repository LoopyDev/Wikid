# Graph Editor Rule Blocks

## Good Candidates For Blocks
- Conditional required (IF status = X → require field Y)
- Visibility/show-hide rules (IF condition → show/hide)
- Editable/locked rules (IF condition → lock/unlock)
- Default/autofill rules (from template/user/other field)
- Validation rules (regex, min/max, allowed values)
- Relation constraints (must reference from table/with filter)
- Workflow/state transitions (status change triggers requirements)
- Calculated fields (derive from other fields)

## Less Worth A Block
- Static required toggle
- Label, description, placeholder, help text
