# Block Types and Tune Menu Options

Overview of blocks we support in the Tiptap editor and the controls that should appear in the tune menu for each type.

- **Paragraph**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Colour: Text colour, Highlight
  - Delete

- **Heading 1 / Heading 2**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Colour: Text colour, Highlight
  - Delete

- **To‑do (task list item)**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Colour: Text colour, Highlight
  - Delete

- **Bulleted list item**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Colour: Text colour, Highlight
  - Delete

- **Numbered list item**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Colour: Text colour, Highlight
  - Delete

- **Image**
  - Delete
  - (No “Turn into” and no “Colour” menu)

- **Horizontal rule / Divider**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Delete
  - (No Colour menu)

- **Page link**
  - Turn into: Paragraph, Heading 1, Heading 2, To‑do, Bulleted, Numbered
  - Delete
  - (No Colour menu)

- **Database table view**
  - Delete
  - (No “Turn into” and no “Colour” menu)

- **Table of contents**
  - Delete
  - (No “Turn into” and no “Colour” menu)

- **Columns**
  - Delete (on the columns container)
  - (No “Turn into” and no “Colour” menu; per-column handles insert blocks and resize)

Notes:
- “Turn into” options collapse into a single submenu/panel, but the available targets above should still be offered based on the current block type.
- “Colour” (text colour + highlight) should only appear on text‑based blocks (paragraphs, headings, list items, task items).
