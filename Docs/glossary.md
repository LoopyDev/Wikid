# Glossary

- Personal workspace (core): Auto-generated workspace tied to a user's UUID via `Workspace.personalOwnerId`. The personal owner is always an `OWNER` in this workspace; their role cannot be changed or removed.
- Setup page: A newly created page entry that is visible in the sidebar but still pending configuration. Setup pages can stay unfinished and be revisited later. Titles persist when edited; completion finalizes the page type.
